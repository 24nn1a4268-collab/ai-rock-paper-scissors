# 🎮 AI-Based Rock, Paper, Scissors Game

An AI-based Rock Paper Scissors game built using Python and Machine Learning (Scikit-learn). The system learns from player behavior and predicts the next move using a Logistic Regression model.

## ✨ Features

- User vs Computer interactive game  
- Machine Learning-based prediction system  
- Learns player patterns over time  
- Logistic Regression model (Scikit-learn)  
- Real-time score tracking  
- Simple and beginner-friendly AI project  

## 🧠 Technologies Used

- Python  
- NumPy  
- Scikit-learn  
- Random library  

## ▶️ Run the Project

```bash
python rps_ai_game.py
```

## 🧠 How It Works

1. User enters a move: rock / paper / scissors  
2. Game stores previous user moves  
3. Machine Learning model trains on past data  
4. Model predicts the next user move  
5. Computer selects the best counter move  
6. Score is updated after each round
